# Extension Directus — parametres-publics

Endpoint public :
GET /parametres-publics

Il renvoie uniquement :
- comptes_investisseurs
- mode_acces_business_plan

Installation :
1. Copier le dossier `directus-extension-parametres-publics` dans `CRI_Projets/extensions/`
2. Redémarrer Directus : `docker compose restart directus`
3. Tester : `http://localhost:8055/parametres-publics`
